# auspex

Pure-Dart headless state machine base (`AuspexMachine`), `IntrospectionNode` tree, `ls` / `do` command interpreter (`AuspexProtocol`), loopback debug server (`AuspexSocketServer`), and standalone socket CLI client (`bin/auspex.dart`).

See the root [README](../../README.md) for quickstart, codegen pairing with `auspex_gen`, and protocol usage.
